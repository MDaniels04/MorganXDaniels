Siida

Siida is an old project I created for my A level Computer Science None Examined Assesment (NEA) using Python and Pygame. It simulates a small number of villagers trying to survive in an icy wilderness by building houses, hunting and migrating along with the seasons.
It utlisises the A* algorithm both for pathfinding, and a version of Goal Oriented Action Planning where "actions" are assigned a coordinate value to "pathfind" between. While I have certainly learnt a lot about programming since, its still an interesting project to look back on and think about how I could improve it if I were to do it again.
